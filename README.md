# Golden Clean Solutions · Punto de Venta

Sistema web de recepción y control de servicios para el atelier de Golden Clean Solutions (León, Gto.).

- Folio de servicio automático, uno por par o prenda.
- Clientes con número y grupo automático (Nuevo / Frecuente / Única vez).
- Catálogo de servicios con precio y tiempo de entrega; catálogo de marcas con alta gama.
- Orden de servicio (nota) con rango de folios, imprimible y para WhatsApp.
- Etiquetas por artículo.
- Caja: anticipos, pagos, venta de productos.
- Corte de ventas por día, semana, mes, trimestre o rango, con comparativo y descarga a Excel.
- Usuarios con acceso por bloques y usuario master.

HTML + JavaScript estático (GitHub Pages) con base de datos Supabase (Postgres + Auth + RLS).
